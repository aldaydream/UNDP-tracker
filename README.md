# AMF 2026 Bangkok · трекер участников

Каждые 3 часа скрипт скачивает публичный список участников Annual Meetings 2026 из IMF Connect (тот же источник, что у приложения «IMF | World Bank Meetings»), сравнивает его с прошлым снимком и сохраняет, кто появился в списке и кто из него пропал. Сайт показывает это с фильтрами по категории, стране, подкатегории, периоду, с поиском и выгрузкой в CSV.

**Источник:** `https://www.imfconnect.org/content/dam/imf/AMAttendeeList/AMAttendeeList.json`
На 01.10.2026: 8 884 записи, категории Delegates, Observers, Guests, Press, CSO.

**Что хранится:** имя, должность, организация, страна, категория, подкатегория, темы интересов, дата появления и дата выбытия. Email, биографии и ссылки на профили из источника отбрасываются.

```
index.html                     сайт, один файл
data/participants.json         все, кто когда-либо был в списке, с датами (пишется при изменениях)
data/status.json               время последней проверки (пишется каждый запуск)
scripts/update.py              сборщик, Python 3, без зависимостей
.github/workflows/update.yml   запуск каждые 3 часа + ручной запуск
vercel.json, robots.txt        запрет индексации поисковиками
```

## Запуск, ~15 минут

### 1. GitHub
1. github.com → **New repository** → имя, например `amf2026-tracker` → **Public** → Create.
   Публичный репозиторий выбран сознательно: на бесплатном тарифе GitHub расписание в приватных репозиториях срабатывает ненадёжно. В репозитории лежит только публичный список без email.
2. Ссылка **uploading an existing file** → перетащить всё содержимое папки, включая `.github` → **Commit changes**.
   Если папка `.github` не загрузилась: **Add file → Create new file**, имя `.github/workflows/update.yml`, вставить содержимое файла.
3. Вкладка **Actions** → включить workflows, если GitHub спросит → **Update participants** → **Run workflow**.
   Через 1–2 минуты в репозитории появятся `data/participants.json` и `data/status.json`. Это стартовый снимок: все, кто в списке на этот момент, получают отметку «старт».

### 2. Vercel
1. vercel.com → **Add New → Project** → Import этого репозитория.
2. Framework Preset: **Other**. Остальное оставить по умолчанию → **Deploy**.
3. Дальше сайт обновляется сам после каждого коммита с данными.

### 3. Доступ для коллеги
- Достаточно ссылки: сайт закрыт от поисковиков, адрес знают те, кому его дали.
- Для закрытого доступа: Project → Settings → **Deployment Protection** → Vercel Authentication → **All Deployments**, затем создать **Shareable Link** для коллеги. На Hobby это бесплатно.
- Условия Vercel Hobby: личное некоммерческое использование. Для рабочей задачи тот же репозиторий подключается к Cloudflare Pages без изменений в коде.

## Как читать сайт
- **новый** — человек появился в списке после старта отслеживания.
- **выбыл дд.мм** — пропал из списка в эту дату. Если вернётся, снова станет «новым».
- Клик по столбику графика открывает список за этот день, клик по плитке сверху включает быстрый фильтр.
- Период **«с прошлого визита»** показывает новых с прошлого открытия сайта в этом браузере.
- Фильтры записываются в адрес страницы: ссылку с нужной выборкой можно переслать.
- Время везде бангкокское.

## Если что-то сломалось
- На сайте красная надпись «проверка давно не проходила» → GitHub → Actions → последний запуск → лог. Чаще всего источник был временно недоступен, следующий запуск через 3 часа исправит.
- Защита от сбоев источника: если пришло меньше 70% от текущего списка, скрипт ничего не меняет и завершается с ошибкой, GitHub присылает письмо.
- Vercel пишет «Deployment Blocked … commit author»: на Hobby деплой принимается только от владельца. Workflow подписывает коммиты именем владельца репозитория, поэтому Vercel-аккаунт должен быть привязан к этому же GitHub-аккаунту.
- Нужен приватный репозиторий: workflow оставить как есть и добавить внешний будильник, например cron-job.org:
  `POST https://api.github.com/repos/OWNER/REPO/actions/workflows/update.yml/dispatches`,
  заголовки `Authorization: Bearer <fine-grained token, Actions: Read and write>` и `Accept: application/vnd.github+json`,
  тело `{"ref":"main"}`, раз в 3 часа.
